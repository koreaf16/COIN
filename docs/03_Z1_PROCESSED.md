# 03. Zone 1 (Processed Data) - 정량화 및 상태 벡터

Z1의 핵심은 수많은 텍스트와 숫자로 이루어진 시장 상황을 수학적으로 비교할 수 있는 **정규화된 공간(Vector Space)**으로 변환하는 것입니다.

## 1. 숫자/텍스트 분리 원칙
*   **텍스트 임베딩 모델(BGE-M3 등)은 숫자의 미세한 차이(예: 0.01%와 0.05%)를 구분하지 못합니다.**
*   따라서 시장의 상태(지표)는 순수 **숫자 배열(Float64)**로 만들어 Cosine Distance 연산을 수행하고, 뉴스나 브리핑 문서만 1024차원의 **텍스트 임베딩 벡터**로 만듭니다.

## 2. 9차원 시장 상태 벡터 생성 (State Vector Builder)
매 15분마다 현재 시장 상태를 아래 9가지 차원으로 압축하여 `z1_market_states` 테이블에 저장합니다. 이 과정에서 `vector-calculators.js` 모듈이 복잡한 지표 계산 및 정규화를 담당합니다.

1.  **변동성 레짐 (Volatility Regime)**: ATR과 볼린저밴드 기준 (0.0=LOW, 0.5=MED, 1.0=HIGH)
2.  **추세 강도 (Trend Strength)**: EMA 12/26 차이 (-1.0 강한 하락 ~ +1.0 강한 상승)
3.  **펀딩비 Z-score**: 최근 30일 평균 대비 현재 펀딩비의 정규화 편차
4.  **OI 변화율**: 최근 1시간 미결제약정 변화율 (%)
5.  **CVD 방향 (Cumulative Volume Delta)**: 매수/매도 우위 (-1.0 ~ +1.0)
6.  **매크로 레짐**: 거시경제 상태 (0.0=Risk Off, 0.5=Neutral, 1.0=Risk On)
7.  **뉴스 센티먼트**: 극단적 공포(-1.0) ~ 극단적 탐욕(+1.0)
8.  **거래소 순유출 (Netflow)**: 온체인 데이터 기준 유출입 (현재 0 고정)
9.  **청산 비대칭성 (Liquidation Asymmetry)**: 현재가 기준 상/하방 청산맵 비율 (-1.0 ~ +1.0)

## 3. 과거 수익률 역산 백필 (Backfill)
벡터가 생성되고 시간이 지나면 백그라운드 프로세스가 작동합니다.
*   **작동 로직**: 벡터 생성 기준 1시간, 4시간, 24시간 뒤의 실제 시장 가격을 조회하여 상승했는지 하락했는지(`next_1h_return` 등)를 DB에 채워 넣습니다.
*   **활용**: LLM이 현재 시장을 분석할 때 오라클 DB에서 현재 9D 벡터와 가장 코사인 거리가 가까운 과거 50개의 시점을 검색(`VECTOR_DISTANCE`)합니다. 그리고 "비슷했던 과거 50번 중 70% 확률로 4시간 뒤 하락했습니다." 라는 통계적 팩트를 LLM에게 쥐여줍니다.
