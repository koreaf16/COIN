## 판정 기준

- `완료`: 현재 코드 경로에서 실제 동작까지 연결됨

## 체크리스트

| ID | 가이드 항목 | 상태 | 현재 반영 내용 |
| --- | --- | --- | --- |
| 1 | `1h`, `4h`, `1d` 데이터를 본다 | 완료 | RingBuffer와 Oracle Reader가 다중 시간대 Kline을 사용한다 |
| 2 | `1d -> 4h -> 1h` 계층으로 판단한다 | 완료 | 스냅샷, 프롬프트, 저장 전 검증, Rule Engine 구조 가드까지 연결됨 |
| 3 | 큰 흐름 역행 진입을 피한다 | 부분 | 구조 가드와 market guard가 있으나 BTC 일봉 정합성은 전 구간에서 강제되진 않음 |
| 4 | 상승 추세에서는 눌림목을 우선 본다 | 부분 | `pullback_*` setup이 계산되고 플랜 조건으로 사용할 수 있으나 전용 주문 로직은 없음 |
| 5 | 박스 돌파/리테스트를 본다 | 부분 | `breakout_*`, `retest_*` setup이 계산되고 노출되지만 별도 실행 분기는 없음 |
| 6 | 지지/저항과 거래량을 함께 본다 | 부분 | support/resistance 거리와 `volume_surge`는 있으나 둘을 함께 강제하는 규칙은 없음 |
| 7 | 4시간봉 추세와 ATR을 본다 | 완료 | 4h 기반 구조와 ATR이 프롬프트, 실행, Smart Exit에 반영됨 |
| 8 | 1시간봉 RSI를 본다 | 부분 | RSI는 프롬프트 제약에 반영되지만 런타임 강제 규칙은 약함 |
| 9 | BTC 방향을 함께 본다 | 부분 | BTC 모멘텀, `btc_daily_bias`, market guard가 있으나 모든 경로의 하드 가드는 아님 |
| 10 | 대형 코인 위주로 운영한다 | 부분 | 기본 코어 심볼은 `BTC/ETH/SOL`이고 flex 심볼은 환경 설정 기반 |
| 11 | 진입보다 손절을 먼저 정한다 | 완료 | stop_price, stop_conditions, time_stop_min이 저장 전 검증 대상이다 |
| 12 | 최소 손익비를 강제한다 | 완료 | 최소 `R:R 2.0`이 저장 전 검증에 반영됨 |
| 13 | 손절폭 기반 포지션 사이징을 쓴다 | 완료 | Risk Gate가 `허용 손실금 / 손절폭` 기준으로 포지션 금액을 계산한다 |
| 14 | 일일 손실 한도를 둔다 | 완료 | 일일 손실 한도 초과 시 진입을 막는다 |
| 15 | 동시 포지션 수를 제한한다 | 완료 | `maxOpenTrades`가 적용된다 |
| 16 | 고레버리지를 피한다 | 부분 | 기본 최대 레버리지는 낮게 잡혀 있으나 환경 설정 변경은 가능하다 |
| 17 | 계획 없는 추가매수를 금지한다 | 부분 | 동일 심볼 중복 진입은 막지만 planned scale-in 모델은 없다 |
| 18 | 계획된 분할 진입을 지원한다 | 미반영 | scale-in 구조와 구간별 진입 모델이 없다 |
| 19 | 주문 방식을 전략별로 구분한다 | 부분 | 눌림/리테스트 성격은 `LIMIT`, breakout trigger 성격은 `MARKET`로 분기한다. 다만 사전 배치형 stop-entry는 아직 없다 |
| 20 | 진입 직후 보호 주문을 건다 | 완료 | stop market, take profit 주문이 진입 직후 배치된다 |
| 21 | 트리거된 플랜은 소모한다 | 완료 | 진입 성공 후 플랜이 `TRIGGERED` 처리된다 |
| 22 | 뉴스/이벤트/매크로를 함께 본다 | 부분 | 프롬프트와 일부 guard는 반영하지만 명시적 entry field로 완전히 표준화되진 않음 |
| 23 | ATR/트레일링/시간 손절/무효화 청산을 쓴다 | 완료 | Smart Exit가 다중 청산 경로를 운영한다 |
| 24 | 부분 익절을 기록과 성과에 반영한다 | 완료 | `PARTIAL_EXIT`가 DB, 누적 손익, 복구 경로까지 반영된다 |
| 25 | 매매 이유를 기록한다 | 완료 | `entry_reasoning`, trade log, logic checks가 남는다 |

## 현재 결론

현재 시스템은 `스윙 구조`, `손절 기반 리스크`, `플랜 소모`, `부분 청산 기록`까지 반영한 상태다.
